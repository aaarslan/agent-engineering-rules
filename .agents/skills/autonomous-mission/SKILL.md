# Autonomous Mission

Follow the **Autonomous mission** route in [AGENTS.md](../../../AGENTS.md). Let the autonomous workflow route each increment; load contexts only as they become relevant.

Inventory constraints and unknowns, then split the objective into complete behaviors with verification seams. Record decisions so later work does not reverse them. Use specialists only when independent verification or reduced context pressure materially helps; give each a narrow charter.

Finish only when every requested outcome is complete or precisely blocked, each increment passes profile-appropriate checks and real-flow exercise, cross-increment contracts agree, and a full-diff skeptic pass checks regressions, scope creep, contradictions, and unsupported claims.
