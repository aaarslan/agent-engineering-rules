# Adopt AER deliberately

Select the contract profile and representations for your actual clients; preview
before installation and check discovery in a fresh session. `prototype` scales
verification for disposable work, `standard` is the normal profile, and
`high-assurance` increases evidence for costly failures. Correctness, scope and
integrity do not decrease with profile.

Skills work independently. Kernel-only installation uses `--skills none` and
retains the same browser-conditional UI-01 clause. Skills-only delivery includes
local safety context and the web skill's same clause. Load relevant references
only; client-disabled skills must stay disabled. Multiple skills can legitimately
support one task. Native manual controls and restricted tools are integration
properties, not portable prose guarantees.

Use [INSTALL.md](INSTALL.md) for selection changes, v5 exit, ownership and
recovery. Review [capability claims](docs/capability-matrix.md) and
[repository evaluation limits](https://github.com/aaarslan/agent-engineering-rules/blob/main/docs/evaluation.md) before attributing better outcomes or
savings to the guidance. Plugins and other clients are deferred/experimental.
