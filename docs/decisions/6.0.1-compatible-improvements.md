# 6.0.1 compatible improvements

The audit identified useful content, discovery, readability and evidence gaps,
but mixed those with proposals to replace v6 ownership and delivery contracts.
This patch repairs the former while preserving the installed CLI/state schema,
manual-only native controls, restricted reviewer, instruction destinations,
profiles and immutable v5 fixture. It makes no efficacy or cost-saving claim.

## Content and distribution

The manifest now copies the 38 resources named by skill bodies, rather than the
170 resources induced by sibling markdown-link closure. A reference contains
its operative guidance without requiring another reference absent from that
skill. The renderer retires only obsolete copies with the exact generated-source
marker; it refuses contributor-owned files. Consumer removal still requires
recognized package hashes. The 6.0.0 history record was captured from the complete,
unchanged package before editing; the newer installer recognizes all three prior
representations and profile blocks for upgrade/uninstall.

The shared inline safety fragment remains in every standalone skill. Retire the
redundant Local Safety `source/shared/contract.md` reference and its copies; it
was different text from the kernel and is not a second contract authority.
Catalog descriptions distinguish feature implementation, architecture decisions
and touched security boundaries. Manual invocation instructions move into the
portable bodies; native invocation metadata is unchanged. These are routing
hypotheses, not measured activation improvements.

Keep UI-01 browser-conditional in the kernel and web skill. File extension rules
are an incomplete substitute: Claude's path rules activate on matching file-tool
operations, and a browser behavior investigation can need the clause before any
UI file is touched. Removing the existing delivery before a matched trial would
trade a known observed failure for an unmeasured omission. The clause has one
wording authority; no new UI obligations are introduced.

The kernel retains AE-01–AE-26 and expands the slash-joined investigation checklist
into ordinary words. Physical wrapping improves readability without increasing
obligations. Profiles remain compatible install selections; adoption guidance
makes task risk authoritative within the repository default. Rule deletion or
per-task profile machinery needs evidence beyond this patch.

## Platform options and installer

README now starts with behavior, an example skill and installation. Document the
existing `.claude/rules/aer.md` instruction destination as a Claude-only option;
its owned managed block does not need a CLAUDE import. The default remains
AGENTS.md, with its conditional Claude fallback clearly disclosed. Document
portable installation through Vercel's skills CLI, including the missing kernel,
native controls and reviewer adapter. That command already discovers the source
skills; no competing layout or new installer is necessary.

Current official documentation also exposes plugin skills/agents/hooks/output
styles. A forced output style can carry persistent contract instructions while
retaining coding instructions, but overrides the user's selected style and can
lose to another forced plugin style. This is now in the capability table as a
possible distribution channel, not a tested AER artifact or default.

Keep the reviewer restricted to Read/Grep/Glob. Subagent tool inventory and command
permission patterns are different controls. A blanket `git diff` allowance is not
read-only: git supports `--output`, external diff and textconv. Supply a complete,
bounded review packet and document safe caller commands instead of silently
broadening reviewer authority.

Format the runtime and rename opaque bindings in payload construction and mutation
coordination. Retain journal, lock, snapshot and package-history protections.
Git cannot restore ignored/untracked consumer material, establish deletion
authority, or classify an interrupted multi-destination operation. Removing those
contracts is a redesign requiring separate fault/race analysis. Keep Node 24.11.1
until the supported filesystem identity checks pass on Node 22 on both Windows
and Linux; a local bypass of the engine gate is insufficient support evidence.

## Research and checks

Archive [unused model-overlay hypotheses](6.0.1-model-hypotheses.json) under this decision directory and remove
the live compatibility validator's model-expiry requirement. They were never
rendered; archival creates no model-specific runtime behavior. Preserve the
frozen history/source migration records and v5 fixture assertions required by
AGENTS.md. Replace identical task seeds with thirteen distinct development
projects covering persistence, interrupted work, authorization, real loopback
HTTP/partner contracts, browser state and other task-specific behavior.

Each of the 39 cases names its full disclosed contract and intended directive
coverage. Eighteen executable case checks detect the unmodified seed's defect;
fixture validation runs only in disposable copies. Baselines establish setup,
not acceptance. Browser focus, architecture quality and review/doc artifacts
still require observation or rubric grading. Public third cases are prospective
holdout candidates, not hidden tasks. Production-repository validity, adherence,
cost, kernel ablations and implicit routing remain unmeasured.

Run research validation once in its separate CI job while retaining runtime,
legacy and packed-install checks in every operating-system/runtime cell. The
previous matrix's 20-minute timeout was not its observed duration: v6 release
run 37151350575 took roughly 2.5–5.8 minutes per runtime cell. This patch removes
redundant research execution without dropping cross-platform lifecycle checks.

Live provider/model trials remain pending exact provider/model and spend
authorization under `docs/evaluation.md`. No provider dispatch or credentials
enter CI, and no synthetic run is substituted for a live evaluation.

## Observed verification

On macOS arm64 / Node 24.21.0, 38 active tests and 77 original v5 tests passed;
content/link/schema/budget checks, all fixture baselines, 18 seed calibrations and
54 load scenarios passed. Packed installation exercised isolated npm prefix,
collision/drift refusal, interruption/resume, uninstall and the pinned v5 exit.
[Local release record](../evidence/6.0.1-local-release.json).

The exact captured 6.0.0 package upgraded in all three profiles with all three
representations together, removing 396 obsolete reference copies per scenario
while retaining 114. Consumer edits refused before mutation; the upgraded state
was current and idempotent, and uninstall retained consumer bytes.
[Upgrade record](../evidence/6.0.1-upgrade.json).

The preserved CI matrix still needs to execute for this patch. Final-client
controls remain the named 6.0.0 probes. No remote providers were dispatched, and
publication had not been performed at this local verification stage.
