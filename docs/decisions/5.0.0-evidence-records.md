# Repository-only evidence records

Date: 2026-09-12

The product review asked for easier inspection of installation behavior and a
frozen comparative-evaluation protocol. V5's existing evaluation policy already
defines the substantive requirements. Its deliberate rejection of provider
dispatch, benchmark generators, and completion-report enforcement remains in force.

The change adds a small offline record validator and a deliberately incomplete
protocol template under repository documentation. A reviewed owner-authored plan
can be locked against exact bytes and referenced input digests. Externally
collected per-attempt records can then be checked against that identity, planned
cells, statuses, timestamp/order constraints, and available artifact hashes.
Missing evidence, unavailable usage, failed runs, and partial collections remain
explicit. The validator neither executes nor scores work, and its positive
result does not certify authorization, truthful provenance, grading, or efficacy.

This is intentionally narrower than a research harness. V1 accepts one matched
baseline/treatment design with one shared configuration. It has no provider
adapter, cost calculator, repetition dispatcher, automatic project checks, HTML
report, benchmark aggregate, hook state, or runtime completion grammar. Other
designs need an explicit format revision. The package allowlist excludes these
files; the manifest, rule corpus, generated distributions, and installed runtime
remain unchanged.

The installation walkthrough describes an actual provider-free local exercise,
with a regression for the connected collision → preview → install → drift →
deliberate recovery → uninstall path. It distinguishes mechanical ownership
evidence from model behavior and retains the existing interrupted-update tests.

No paid or unpaid model trials were conducted for this change, no empirical rows
were fabricated, and frozen historical evidence was not modified. New test
records are explicitly synthetic format fixtures, not research outcomes. No
efficacy claim is made.
